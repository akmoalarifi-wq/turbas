# ترباس — تشغيل كموقع برابط حي

## أسرع طريقة: رابط من Render (مجاني)

1. ادخل https://render.com وسجّل (بحساب Google يكفي)
2. Dashboard → **New +** → **Web Service**
3. ارفع المشروع:
   - إما اربط GitHub بعد ما ترفع مجلد turbas
   - أو استخدم "Public Git repository" إن رفعته
4. الإعدادات:
   - **Name:** turbas (أو أي اسم)
   - **Runtime:** Python 3
   - **Build Command:** اتركه فاضي أو اكتب: `true`
   - **Start Command:** `python3 server.py`
5. اضغط **Create Web Service**
6. انتظر دقيقتين لثلاث — يعطيك رابط مثل:
   `https://turbas-xxxx.onrender.com`

### الروابط بعد النشر
- موقع العميل: `https://رابطك`
- لوحة الورش: `https://رابطك/partner`

### دخول الورشة التجريبي
- `0500000001` ورشة رقم 1
- `0500000006` محل قطع

---

## تشغيل محلي (جهازك فقط)
```bash
cd turbas
python3 server.py
```
ثم: http://127.0.0.1:5000

السجل التجاري وبوابة الدفع لاحقاً — الموقع يشتغل بالرابط بدونها.
